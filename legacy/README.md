# Legacy material

This directory contains historical upstream targets and experiments that are **not** the current SmartESC G30 firmware.

The active project is documented in the repository root README and in `docs/CURRENT.md`.

Archived here:

- `m365/` — historical M365 target
- `m365.stmcx` — historical motor-control project data
- `docker_build_m365.sh` — old M365 build helper
- `serial-trottle-brake-esp32/` — old ESP32 serial throttle/brake experiment
- `reference-docs/` — old manuals, PDFs and protocol/reference notes

They remain in git for provenance and archaeology rather than being deleted.
